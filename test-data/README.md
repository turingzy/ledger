## 导入防重

把 `import/` 中的 CSV 文件复制到测试设备的文件目录，由 APP 的文件选择器打开。
选择“通用账单”规则，导入账户保持“使用文件中的账户”，默认分类保持未指定。
以下数量以刚补入场景数据、尚未导入样例且未编辑相关交易为前提：

1. `01-known-ids.csv`：5 行，导入 3 笔、跳过 2 笔。两笔已存在咖啡交易的交易号不同，均应保留；第三笔同内容咖啡具有新交易号，也应导入。再次导入此文件应为导入 0 笔、跳过 5 笔。
2. `02-without-ids.csv`：4 行，提示 1 笔疑似重复。“跳过重复”应导入 3 笔；“仍然导入”应导入 4 笔。两笔完全相同的新早餐均应保留。选择跳过后，再导入同一文件应提示 4 笔疑似重复，继续跳过则导入 0 笔。
3. `03-overlapping-file.csv`：先导入文件 01，再导入此文件，应导入 1 笔、跳过 1 笔，证明防重按交易进行，而非按文件名进行。
4. `04-invalid-currency.csv`：第二行交易的币种与账户不符，应报错，整份文件均不写入，余额不变。

备份与恢复仍可使用这些账户和交易测试；恢复账单数据采用完全覆盖。
保存失败需要故障注入，不能由正常测试数据可靠模拟，已有本地单元测试覆盖。

## 主要货币与汇率

启动后直接进入主界面，无首次设置或创建账户引导。语言、主题默认跟随系统，主要货币默认取手机地区对应的货币；可在“设置 → 常规”修改。账户仍在钱包中按需创建。
账本、钱包和分析统一汇总为主要货币；外币交易保留原金额，并在金额左侧显示币种。
首次处理外币历史数据需要联网获取 Frankfurter 历史汇率；离线沿用缓存，也可在“设置 → 常规”填写手动汇率。
可使用人民币钱包和美元现金账户手动新增跨币种转账，检查转入金额、两边余额和转账后的修改操作。
切换主要货币后再切回，已保存的历史换算金额应保持一致。
